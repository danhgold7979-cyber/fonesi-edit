# Pure planning rules v1

## Identity, scanning and names

Source identity=(platform,stable channel/item/media IDs,quality variant,account scope). Display name never identity. Local media strong identity uses content hash, but separate occurrence IDs preserve files in distinct scene positions. Natural C/G sort tokenizes digit groups; casefold Unicode comparison then stable ID tie-break, not locale-dependent iteration. Logical names do not rename files. Real rename requires separate preview/collision/rollback map and never part of import.

Scan multiple explicit roots, canonicalize/deduplicate physical paths, retain per-root/channel ownership, detect symlink/junction loops, exclude configured output/cache/staging paths by canonical ancestry; nested output not reimported. Exclusion/filter/checkbox affects selected set, not source deletion. Filter metadata unknown stays distinguishable from zero duration. All mutation uses immutable selected manifest; cancel before enqueue commits no subset.

Output per channel default `platform/channel__source_id edit/videos/`; alternate `Videos edit/channel__source_id/`. User-customizable folder templates, including Vietnamese names, are accepted after path safety preflight; do not hard-code only these two layouts. Basename date+short title+stable media ID+snapshot suffix; sanitize Windows reserved names/control/invalid chars, trailing dot/space, enforce chosen full path budget, preserve meaningful Unicode. Collision handled by publication no-replace reservation and version suffix, never overwrite. Skip requires same input+config+tool policy and validated matching artifact; same filename insufficient. Missing subtitles default continue with warning; skip or wait only explicit policy. Missing/ambiguous logo/audio/sub references block affected item, not assign arbitrary neighbor.

## Duration

Mode one_video is default: cannot pull another clip implicitly. multi_clip explicit captures ordering/name/time/seed and selected source IDs. Target video/main_audio/manual rational duration. Let output segment duration d_i=(source_out_i−source_in_i)/speed_i plus explicit freeze/repeat extension, with d_i within configured min/max; target D=sum(d_i)−sum(overlap_j). Every overlap>0 <= both adjacent segment durations, no undeclared triple overlap. Enforce all selected required scenes and order, source bounds and speed min/max. Policy precedence: keep required scenes/order→hard limits→selected allocation equal/proportional/weights/manual→optional selected trim/speed/loop/freeze. Infeasible returns exact violated constraints; no silent speed/scene/mode change. Preserve pitch policy explicit. Mapped cues split across repeats and clip at segment boundaries. Audio playlist maps full canonical path/asset ID, not basename; manual list order/duplicates allowed, exact cardinality or explicit looping rule required. SFX triggers compile once from seconds/scenes/ratio into sample-aligned offsets; final timeline duration drives offsets, not original duration.

## Matrix

Each row selects one valid angle per required ordered scene. W nonnegative integer: same asset/content identity cannot recur at same scene position in preceding W rows. K integer0..scene_count: Hamming differences at least K against previous row or all rows within W, explicit `k_scope`. With W=0 and window scope compare set empty; adjacent scope still compares previous. Unique combination default on across project history; configurable wider scope requires explicit selected history snapshot. Balance is soft objective after hard feasibility, minimize usage imbalance with deterministic seed tie-breaking.

State history planned/reserved/running/succeeded/failed/canceled; reservations count for uniqueness while live. Failed rows are retried under same combination/snapshot, not silently regenerated. Transactionally reserve all submitted rows with jobs; cancellation before commit rolls back entire request. On validated artifact commit mark succeeded atomically via JOBS contract. Different filename cannot bypass identical-content duplicate constraints. Edited row invalidates dependent W/K window checks; lock cell persists through regeneration, and contradiction returns error.

Generator inputs: ordered scene/angle IDs/hashes, locked cells, N,W,K,k_scope,unique,seed,algorithm_version,history digest, time/node budget, cancel. Lazy bounded candidate generation, never full product for large case. Return rows+status complete|partial_budget|canceled|proven_infeasible with explored counts; timeout is not proof. Small Cartesian oracle validates feasibility and constraints; large benchmarks assert memory/budget, not global optimality. Same seed only reproduces with same inputs/order/history/algorithm. Preview/CSV/queue use exact row snapshot including audio and duration, never reconstruct from display C/G strings.
