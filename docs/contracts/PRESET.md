# Preset and scoped commands v1

Preset envelope: schema_version1, UUID, immutable version integer>=1, name, groups (video/text/subtitle/logo/mask/motion/audio/output/automation), asset refs, parent version optional, provenance. No source media IDs/credentials/browser data in shared preset; referenced user assets remain references with missing-resource diagnostics. Import rejects unknown version/keys/nonfinite values/duplicate JSON keys before state mutation. Export revalidates and redacts secret sentinel fields by allowlist, not regex alone. Version migration explicit with backup; invalid import leaves project and registry unchanged.

Per property resolution: app default→preset value→clip override. Locked property preserves its current resolved value/keyframes, even if inherited; locking snapshots that value. Auto can only change non-overridden/unlocked fields. Explicit user edit may change selected locked field only after unlock; auto reset never unlocks implicitly. Reset selected override restores inherited value, but refuses locked field until unlock. Nested property paths and keyframes have independent provenance; copying font group cannot replace motion or cue text. Reset group preview lists every changed/retained path.

Examples (default x=0.5, preset x=0.2): no override resolves0.2; override0.7 resolves0.7; lock0.7 + auto0.1 remains0.7; reset unlocked override→0.2; newer preset0.4 changes only inherited unlocked clips; selected clip override0.7 and keyframe locked at t1 remain unchanged. Cue manual text lock is independent of its style. Batch applies selected clip IDs captured at confirmation, not newly selected UI state.

`preview_apply(scope,properties,preset_version,project_revision)` returns changed/retained/missing-resource list and revision token. `commit_apply(token)` CAS rejects stale project, produces one undo command with before/after for affected paths; cancel token changes nothing. Undo/redo restores values/provenance/locks atomically. Canvas drag collects transient values; mouse release commits one command, Esc restores starting values. Autosave persists only completed commands.

Enqueue resolves full values/assets/tool requirements and freezes snapshot hash. Pending-job replacement is explicit preflight+new snapshot version, rejects running states; no later preset mutation changes current jobs. Cross-phase tests include nested partial copy, mixed selected clips, stale preview, cancel, drag repeated events, keyboard undo with text focus, save/open semantic equality and snapshot immutable across preset update.
