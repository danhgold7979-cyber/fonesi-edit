# CompositionPlan v1 — normative domain contract (proposal for P02 validation)

No legacy implementation imported. Version is `schema_version:1`, evaluator revision `eval-1`; unsupported versions are rejected without rewriting original. UTF-8 JSON forbids NaN/Infinity, duplicate keys, unknown fields and secrets. Canonical encoding sorts keys, uses compact separators and UTF-8. Two digests are distinct: execution_snapshot_digest hashes the full immutable envelope including resolved paths/tool versions/account refs; render_content_digest hashes a documented projection excluding path_ref.path/base, project/asset UUID spelling, revision/provenance, and tool install paths, while replacing asset/font references with content hash+selected stream descriptor and preserving ordered clip/layer semantics, evaluator/generator revision, all rendered values, output format and tool build hash. No field may be excluded merely because convenient. Projection must include referenced font fallback order/hash, source PTS/timebase, selected audio/video stream and all cue/time bindings. Cache uses render_content_digest only when relocated assets are reverified by content+stream; execution and recovery use execution_snapshot_digest. Golden test: same bytes/streams/fonts moved to new paths yields equal render-content digest and different execution digest; changed stream/tool/font/time map yields different render digest. Numeric values below use rationals `[integer numerator, positive integer denominator]` reduced to canonical form; bool is not an integer. UUID strings identify objects. Draft may contain missing refs but cannot compile/enqueue until resolved.

## Required root shape

| Field | Type / invariant |
|---|---|
| schema_version / evaluator_version | exact integer 1 / string eval-1 |
| id / revision | UUID / nonnegative integer; editing creates new revision |
| output | width,height positive even integer for default yuv420p; fps positive rational; duration positive rational seconds; sample_rate integer; channel_layout enum mono/stereo; color_space bt709 default; pixel_format yuv420p default; container mp4, video_codec h264, audio_codec aac default; unsupported alternatives need capability check |
| assets | ordered list of Asset with unique id; no external URI auto-fetch |
| clips | ordered list of Clip; explicit gaps and overlap transitions |
| layers | ordered list of Layer; order explicit, no dict iteration dependence |
| audio | ordered list of AudioClip and master processing |
| transitions | explicit video/audio overlap records with left/right clip IDs and duration |
| fonts | FontAsset list with hash, face index, family/style, fallback refs, license/provenance refs |
| seed / algorithm_revision | unsigned 64-bit integer / exact generator revision |
| provenance | project UUID/revision, preset ID/version/hash, source/account references only |

Asset: `{id,kind:video|image|audio,path_ref,sha256,probe}`. Probe: container duration summary and typed streams only. Every stream has index/codec/time_base/start_time/duration. Video stream owns width/height/SAR/rotation_degrees/display_matrix/frame_pts; audio owns sample_rate/channel_layout/channels; subtitle owns language/subtitle_format; image owns dimensions/SAR/orientation. No global geometry/audio fields may override selected-stream metadata. Clip/audio/cue references must resolve matching stream types. Source in/out are relative to selected stream origin; evaluator applies stream start_time exactly once into its asset/segment mapping, never reuses another stream offset. Fast stat fingerprint is invalidation hint, not identity proof. Missing/changed hash requires relink/preflight, never silently substitutes content.

Clip: `{id,asset_id,video_stream_index,source_in,source_out,output_start,speed,fit,crop,transform,color}`. video_stream_index selects a probed video stream (null only for image); no implicit first-stream switching on retry. Source range `[in,out)` within probed interval; speed>0. Output end is `output_start+(out-in)/speed`. Crop normalized left/top/width/height with positive dimensions, bounds within displayed source; fit contain/cover/stretch with explicit background color/blur. Transform includes flip_x/y, rotation, position and scale. Clip speed affects its linked audio/cues via the same map. Repeating a clip creates explicit segments with unique IDs; freeze is explicit last-source-frame segment, not speed zero. Ordered clips may overlap only through valid transitions; gap default black/silence.

Layer: `{id,type:mask|logo|text|subtitle,z,intervals,transform,style,content,keyframes,visible,locked_fields}`. Z total order uses `(z,id)`; default video→mask→logo/text/subtitle only establishes initial z, not an immutable restriction. Intervals are nonempty, sorted, disjoint half-open output seconds; no implicit forever past output duration. Transform stores normalized position x/y, positive width/height or scale, anchor enum nine points, clockwise degrees, opacity [0,1]. Negative positions allowed only with explicit out-of-frame warning; renderer does not silently clamp. Masks: rectangular rounded shape; mode blur/mosaic/color; amount, feather, radius, RGBA validated by engine capabilities. Logos reference image ID and optional source crop. Text references FontAsset, content, font size in output pixels, spacing/line spacing, wrap width, alignment, max lines, overflow policy (wrap/shrink bounded/warn), fill/outline/shadow/background/padding/radius. Subtitle content references cue IDs/language track and original/translated bilingual linked blocks with independent style/visibility. Missing glyph/font blocks parity certification; explicit user fallback persists its resolved hash.

Keyframe: `{property,time,time_mode,reference_clip_id,value,easing}`. Property path from supported animatable registry (x/y/width/height/scale/rotation/opacity); time absolute rational seconds or normalized rational [0,1] with explicit mode. Relative time maps to referenced clip output_start + relative time × clip output duration; null clip ref uses whole output duration. Absolute mode requires null reference. Layer active intervals mask the result without redefining keyframe time. Duplicate effective time per property invalid. Before first/after last hold nearest keyframe. Between frames evaluate linear, ease-in u², ease-out 1−(1−u)², ease-in-out 3u²−2u³; rotation interpolates numeric degrees (no hidden shortest-path). Lock prevents editing/auto, not evaluation. Motion presets compile into immutable keyframes/analytic segments tagged with evaluator revision and seed, never independently randomized in preview/export. Unsupported path/easing is typed error, not ignored.

AudioClip: `{id,asset_id,audio_stream_index,source_in,source_out,output_start,speed,preserve_pitch,gain_db,pan,mute,solo,fade_in,fade_out,role}`. audio_stream_index explicitly selects an existing audio stream; its start_time/time_base are part of mapping, so delayed tracks remain delayed unless user offset explicitly changes them. Role original/main/music/sfx; ranges and mapping same Clip; gain finite dB; pan [-1,1]. Solo audible set is nonmuted solo clips if any, otherwise all nonmuted clips. Loop/crossfade/SFX triggers compile to explicit repeated instances and exact offsets before snapshot. Ducking is a pre-sum per-target-clip operation, never automatic master attenuation. Policy has target_audio_clip_ids (normally music), source_mode marked_intervals|signal_envelope, sidechain_audio_clip_ids for measured mode, threshold_db, attack/release, intervals with gain, and measured envelope hash when used. Referenced targets/sources must exist and be disjoint unless explicitly validated; narration/main audio is not attenuated merely because music ducking enabled. No fabricated speech detection. Master: sample rate/layout, explicit normalization target (LUFS/peak), optional limiter and measured report. Silence generated only where intentional and reported when required audio is missing.

## Authoritative evaluation and order

`validate(plan, asset_catalog, capabilities) -> diagnostics[]`; error blocks compile, warning requires displayed acknowledgment policy. `evaluate(plan,t) -> EvaluatedFrame(layers,source_requests,audio_spans,diagnostics)` is pure and shared by preview/compile; arbitrary Qt painter transforms cannot redefine export geometry. `compile(plan, capabilities) -> ExecutionPlan(steps,expected_artifacts,tool_leases)` either supports every enabled property or errors by property path. No successful partial render.

1. Resolve asset orientation/SAR into displayed source coordinates; decode source frame by presentation timestamp (latest PTS ≤ requested source time).
2. Intersect source range, map output time `s=in+(t-output_start)*speed`; clips/cues use same segmented map. Trim precedes speed. For subtitles, intersect each source cue with each segment, map both endpoints and preserve provenance.
3. Crop displayed source; apply flip/rotation; fit canvas and explicit background; color transforms in declared order brightness→contrast→saturation→gamma→temperature.
4. Composite clips/transitions; evaluate layers at t; resolve font layout using same raster/layout provider for preview and export; apply local size/crop, anchor-relative scale/rotation, translation, opacity then z-order compositing. Mask samples already composited underlying pixels at its z.
5. Evaluate/mix audio resampling/time map→pitch policy→gain/pan→fades/ducking→sum→normalization/limiter. Audio crossfade overlap participates in duration equation.
6. Convert final pixel/color/output codec. Proxy changes decoded resolution, never logical coordinates, timing or font metrics.

Time remains rational until raster/sample boundary. Output frame n samples t=n/fps, n in `[0,ceil(duration*fps))`; final duration policy rounds to complete output frames and reports exact rational duration. Sample index is floor(t*sample_rate); negative input clipped before indexing. UI time display is rounded only for display. Pixel positions use half-up rounding (`floor(x+1/2)`) at raster boundary; no repeated integer rounding through transforms. Out of range evaluate returns typed range error; half-open end is not active.

High-quality preview uses the canonical compositor path at the requested output frame; responsive draft preview is explicitly labeled until parity verified. P02 must prove shaping/filter engine choice before full P04/P07. Schema acceptance does not mean any engine implements all fields.

## Mandatory tests / pass definitions

Schema missing/unknown/invalid-ref/nonfinite/duplicate-ID/timepoint cases; rational NTSC and VFR boundary mapping; noncentral anchors/rotation/opacity/layer order; Vietnamese/Chinese glyph/fallback/wrapping; each easing boundary and seed determinism; crossfade duration/audio sample count; mute/solo; missing capability must fail. Same snapshot yields identical evaluated geometry on preview/export. Pixel/audio tolerances and sentinel failure probes in VERIFICATION.md. Every schema field must map to criterion, evaluator test and UI/editor use before P07 acceptance.

## Machine-readable schema

`../schemas/composition-v1.schema.json` is the Draft2020-12 structural design. Its R01–R14 comments enumerate mandatory semantic validators not expressible as simple JSON types. It is not a runtime validator or acceptance claim. Audio root contains `clips` plus `master`; root/record field names use the schema. Clip output duration includes explicit freeze_duration extension after source mapping; freeze holds last source frame with audio silence unless an explicit audio plan says otherwise. Defaults must be materialized before canonical serialization; schema has no hidden coercion.

## Cue provenance and resolved timing

Cue source record contains `time_basis: source|output`, `asset_id`, `subtitle_stream_index` (null for sidecar), `source_track_id`, `sidecar_origin`, `segment_ids`, start/end rational seconds and text/language/lock. Source-basis requires asset+track binding and explicit clip segment IDs; each segment must reference that asset. Same asset appearing twice requires two segment IDs, not an ambiguous asset-only map. Output-basis requires asset/stream null and no segment IDs; start/end already in output time. Evaluator returns ResolvedCue `{id,source_cue_id,segment_id,output_start,output_end,text,language,style_ref}` separately for each intersection/occurrence; do not mutate source cue times. Empty intersection omitted, repeated clip creates distinct output instances. Delayed subtitle stream timestamps normalized against its probe timebase/start_time once. Tests: two video/audio streams with different durations/delays; repeated/same-asset-twice clips with different trims/speeds; source-vs-output cue direct editing; duplicated/unknown segment refs rejected.

Text case transform enum none|upper|lower is explicit before shaping, with locale policy recorded; it does not overwrite source cue text or glossary proper-name policy. Per-word highlighting is not emitted without reliable per-word timestamp provenance. It is not silently synthesized from cue length.

Multi-stream schema example: `schemas/examples/multi-stream-composition.json` binds video1 (portrait/rotated), audio3 (48k stereo delayed250ms), subtitle4 (delayed100ms) from an asset also containing video0 and audio2 with different metadata. It is a structural fixture with dummy paths/hashes, not runnable media or accepted stream-time evaluator. Full tests must compare selected-stream geometry/PTS/audio/sub timing and reject type/index mismatch.

### Selected-stream time origin formulas (no double offset)

Let selected stream start be S and a source-relative timestamp q. Decoder PTS is S+q. Clip `source_in/out` are relative to that selected stream; explicit `output_start` is final output placement. Therefore a video/audio clip maps q to `output_start+(q-source_in)/speed` and must NOT add S again at output. An automatic linked-audio planner may initialize audio.output_start from the audio-minus-video stream offset once; once serialized it is explicit, not reapplied by renderer. Seeking decoder uses S+source_in.

For source cue in subtitle stream with start S_sub and cue-relative endpoints a,b, first form asset PTS a+S_sub,b+S_sub. For each bound video segment with selected-video start S_video, intersect with `[S_video+clip.source_in,S_video+clip.source_out)`, then map endpoint t to `clip.output_start+(t-(S_video+clip.source_in))/clip.speed`. Sidecar source cues must serialize rational `sidecar_origin` (materialized zero default, explicit offset when configured); embedded/output cues use null; output-basis cues bypass this mapping. ResolvedCue retains segment ID to distinguish repeated same asset. A source cue's displayed time and stream origin cannot both already include the same offset; parser normalizes once and records source basis.
