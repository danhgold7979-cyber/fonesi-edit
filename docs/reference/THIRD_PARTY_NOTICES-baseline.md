# Third-party components

This personal-use development build uses Python, Qt/PySide6 (LGPL/commercial terms), FFmpeg/ffprobe (license depends on the included build), yt-dlp, gallery-dl, pysubs2, fontTools, psutil and their dependencies.

The exact Python versions and artifact hashes are in uv.lock. FFmpeg build configuration/version is shipped as ffmpeg-build.txt. Upstream projects: https://www.python.org/ ; https://www.qt.io/ ; https://ffmpeg.org/ ; https://github.com/yt-dlp/yt-dlp ; https://github.com/mikf/gallery-dl ; https://github.com/tkarabela/pysubs2 ; https://github.com/fonttools/fonttools ; https://github.com/giampaolo/psutil .

Google Chrome and Node are separate optional system/app-managed components from their official sources; they are not represented as Fonesi-owned software. Font files remain subject to their own licenses; user-selected fonts are not redistributed automatically.

This notice records component provenance and is not a complete compliance certification for public redistribution. Public release packaging requires collecting applicable license texts and corresponding-source information for its exact binary set; no public binary release is created by the development build script.
