Existing Matrix can scan natural C/G, reorder scenes with persisted per-root order, edit/lock one cell, regenerate rows and render. It cannot explicitly exclude scanned scenes or angles from future generation or pin **one angle of a scene across all new rows**. Do not pretend current row-cell lock fulfills the scene-wide requirement. Synthetic CI is not physical Windows, GPU or release acceptance.

## Work items

1. **Pure selection contract:** implement `select_matrix_scenes` consuming a complete read-only scanned scene manifest and a complete user selection. Validate exact folder identities, boolean scene enablement, checked angle hashes, and a per-scene pinned hash. Reject unknown folders, malformed settings, duplicates, enabled scenes without any angle, pins not selected, zero active scenes, and stale/changed manifests. Renumber logical C indices after explicit exclusion, retain each source angle's path/hash/original G index. Do not mutate scanned media or existing queued render snapshots.
2. **History safety:** extend hash-only SQLite legacy history alignment to allow conservatively projecting a historical full-scene tuple onto explicitly active scenes using the complete original scan as the identity universe. All historical digests must uniquely map to a known source scene. Full old tuples project conservatively onto an explicitly selected subset, preserving duplicate/W/K protections. A known shorter/different historical scene-set lacking an active scene is structurally incomparable and is excluded from that W/K comparison; unknown/removed or cross-scene ambiguous hashes still fail closed. The default helper without an explicit full manifest retains strict legacy behavior. Keep strict existing behavior for default callers. Re-apply the same check in the atomic enqueue transaction; never rewrite prior history or silently relax W/K.
3. **Qt selection UI:** add an explicitly initiated asynchronous scan of source scenes and expandable checkboxes for scenes and candidate angles. Add Pin/Unpin commands for a selected angle in its source scene. Changing selection/pin clears stale planned rows/locks, revokes in-flight generation, regeneration and preview callbacks, and never deletes/renames files. A later Generate rescans and verifies the exact original manifest, applies the checked subset and pins, then runs the existing seeded solver. Persist versioned selection for each source root only with matching exact scan identity on later scans; malformed/stale preferences safely fall back to all selected and show that they were not restored.
4. **Whole-scene pin invariants:** apply a selected pin to *every* newly generated row, show pin in the Qt scene tree, and protect its matrix cells from ordinary unlock/edit/regenerate. A pin with W>0 and more than one new output is infeasible and must fail explicitly (no silent W/K relaxation). Retain existing independent per-cell locks for non-pinned scenes. Reorder transforms pinned columns together with their scene; per-scene weights/manual seconds retain existing safe semantics. Finished/rendering jobs retain their immutable prior data.
5. **Regression and proof:** unit tests for excluding scenes/angles, hash/G identity and immutability, all-or-nothing invalid config, projected history duplicate collision/ambiguous failure, selection+pin with W/K, sorted/reordered scenes; Qt real-tree checkbox/pin interactions, persistence, stale worker and immutable queue, real synthetic FFmpeg render after filtering. Run plan checker and source tests; review Linux/Windows full CI, native host and packaged synthetic proof at exact source/test SHA, no weakened assertions.
6. **Evidence:** only after a real successful CI run update `docs/phases/P09_RESULTS.md`, master plan, coverage, current status and ledger. Keep P09 incomplete until all mandatory gates. Do not merge or force-push to main.

## Bounded acceptance / blockers

- [x] Explicit source scene and angle exclusion is validated, reflected in new preview/render snapshots and does not delete, mutate or silently omit data without explicit user choice.
- [x] Scene-wide pin is stable across generated rows/reorder, refuses impossible W/K and protects locked cells.
- [x] Legacy hash-only history projection is conservative, atomic enqueue rejects old reservation collisions, malformed/stale settings and worker results cannot corrupt state.
- [x] Linux/Windows source + desktop/native-host/frozen packaged synthetic CI PASS on the exact code/test SHA.

**OPEN beyond this slice:** large matrix solver optimality and 100k-row performance, full scene-level exclusion UX/drag with physical Windows devices, same-hash cross-scene identity ambiguity (fail closed until explicit provenance migration), NTFS/exFAT/power-loss, intermittent SQLite issue #6, live Chrome/providers, GPU and installer/device release acceptance.
