# Clean technical design

Generation clean-2026-11-01. This is a new design, no implementation reused. Normative contracts: [Composition](contracts/COMPOSITION.md), [Jobs/publication](contracts/JOBS.md), [presets](contracts/PRESET.md), [planning](contracts/PLANNING.md), [UX](contracts/UX.md), [verification](contracts/VERIFICATION.md); proposals and gates in [ADR](decisions/ADR-0001.md).

Dependency direction: ui→application→domain; infrastructure implements domain ports. Domain imports no Qt/network/SQLite. Application commands own undo/scope/preflight; UI renders truthful state, never calls FFmpeg/network synchronously. Worker isolated processes emit bounded typed progress and results; coordinator alone commits job/artifact/history and publication. SQLite stores durable queue/index/cache, portable project JSON references assets and never embeds secrets/media. User data separates from install; export excludes Chrome profiles and credentials.

Modules to create independently: domain (schema/time/geometry/cues/presets), application (commands/snapshots/workflows), storage (migrations/projects/jobs), workers (process ownership/lease/cancel), media (probe/fingerprint/proxy), composition (evaluator/compile), connectors (identify/enumerate/download/capabilities), translation (provider/cache/quota), dependencies (discovery/trust/install/lease), browser (profiles/bindings/broker/readiness), assembly (duration/matrix), resources (measure/admit/backpressure), ui (eight areas). No file is implemented merely by listing it here.

Ports: connector identify(url)→typed kind/platform/canonical IDs; enumerate(context,filters,cursor,cancel)→items/next_cursor/completeness/warnings; download(item,quality,account_ref,staging,cancel)→staged media, no success until validator. Translation(request_id,cue IDs/text/context/lang/glossary,credential_ref)→mapped cue texts/usage/per-item errors; timestamps stay domain-owned. Every external call bounded/cancelable; unknown billing accounted, no credential contents cross into diagnostics. Account/profile/source rights and connector capability are independent states. Cache namespace includes account identity and relevant schema/tool/model configuration.

Migration writes verified backup before transactional DB change; newer schema opens read-only explanation, never downgrade in place. Project save uses staged file+flush+atomic replacement ONLY for app-owned project target explicitly chosen by user; output media publication uses stricter no-overwrite protocol. Relink requires identity verification and explicit replacement when hash changes. Autosave records committed commands, never drag-in-progress. Cache cleaners use managed ownership/leases, never source/output/profile directories.

See master for phase ownership and branch rules; P01 defines contracts, P02 validates technology, P03 builds fresh runnable foundation; further phases consume the same models and coordinator instead of isolated demos.
