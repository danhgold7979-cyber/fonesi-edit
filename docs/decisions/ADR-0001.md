# ADR-0001 — Clean rebuild technology decisions and experiment register

Status: PROPOSED unless explicitly marked. Owner: clean rebuild implementation owner; independent reviewer checks decisions. Deadlines are gates, not fabricated calendar estimates. Selected architecture: Python/PySide6 domain/application/UI separation, SQLite durable coordinator, FFmpeg/ffprobe media workers. These product-aligned choices permit pure logic implementation now; target tool versions and parity are not yet accepted.

| Decision | Candidates / rationale | Required evidence | Deadline / currently |
|---|---|---|---|
| Dev runtime | Python3.12 vs3.13; pin a tested version, explicit lock generated fresh | local availability, dependency resolution, unit/Qt tests, Windows matrix | P02-01 before P03 manifest; NOT_RUN |
| Preview/font compositor | FFmpeg canonical frame/segment preview vs Qt custom compositor plus parity; prefer one layout/raster authority over duplicate text logic | alpha/CJK/blur/keyframes/audio/seek corpus and parity/performance metrics | P02-04/07 before full P04/P07; NOT_RUN |
| FFmpeg distribution | approved Windows builds with verified provenance/license vs user-selected existing installation; Linux system executable dev only | exact build flags, required filters/libass/codecs, hashes/license and media tests | P02-01/09 before bundle/install; NOT_RUN |
| Downloader adapters | yt-dlp/gallery-dl independently versioned; capabilities cell-based | permitted live pagination/download/sub/auth/sync, actual versions and failures | P02-02 before claiming each P05 capability; NOT_RUN |
| Translation | configured remote provider vs local model; adapter portability; no paid auto-selection | glossary/context quality review, latency/usage/cost limits, license/model footprint | P02-03 before provider acceptance; NOT_RUN |
| Chrome session handoff | official supported browser extension/native broker or supported connector interface; reject DB-copy/decrypt/protection bypass | official Windows Chrome versions, account identity and open/lock lifecycle, bridge private scope | P02-10 before authenticated P05 availability; NOT_RUN |
| Package | PyInstaller onedir/portable vs installer wrapping; app opens without external media tool | frozen Windows startup then actual media/font/project/restart on clean machine | P02-06 then P12; NOT_RUN |
| Tool trust | pinned signed/hash manifest from verified publisher, versioned managed root, no system mutation | download interruption/checksum/archive attack/activation/lease/rollback | P02-09 then P03-08; NOT_RUN |
| Performance/concurrency | measured reference budgets, one render initial safe admission until benchmark | VERIFICATION protocol on declared hardware; GPU modes separately | P02-05/07 before production default recommendations; NOT_RUN |
| Persistence | versioned JSON project + SQLite job/index/history; durable publication journal | state-CAS/crash points/no-overwrite/fault OS tests | P03-02/04/06 before real queue success; proposed contract |

Decision closure records chosen versions/hash, alternative rejected with evidence, failed/blocked cases, migration/compatibility implications and exact requirement criteria. External absence permits independent code, never an unverified “works” choice. No installer/FFmpeg/font redistribution until license/provenance verified for selected actual artifacts; preserved historical notices only reference, not current compliance certification.
